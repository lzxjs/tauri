# 应用批量启动器功能实现（最终版）

## 需求概述
实现一个应用批量启动器，支持：

- **拖放** Windows 程序快捷方式 / 可执行文件到界面
- 在列表中 **管理（查看 / 单删 / 批量删）** 这些程序
- 一键 **批量启动** 列表中的所有程序

## 功能特性

1. **拖放添加**：
   - 支持 `.lnk`、`.exe`、`.url` 等文件
   - 通过 Tauri 2 的 `webviewWindow.onDragDropEvent` 获取本地路径
2. **列表展示**：
   - 使用 Ant Design Vue `Table` 展示程序名称、路径、添加时间
3. **单条删除**：
   - 每行有「删除」按钮
4. **批量删除**：
   - 支持勾选多条后，一次性批量删除
5. **批量打开**：
   - 支持「启动选中」与「本场景全部」两种方式
   - 启动间隔 300ms，避免瞬时启动过多程序
6. **场景/分组管理**：
   - 为每个应用记录 `scene`（场景名），默认归入「默认场景」
   - 顶部下拉选择当前场景，表格只展示该场景下的应用
   - 可在行内通过「改场景」按钮调整应用归属场景
7. **数据持久化**：
   - 使用 Tauri Store 持久化到 `app-launcher.json`
   - 应用重启后自动恢复列表

## 技术实现

### 后端（Rust / Tauri）

- **依赖**：
  - `tauri-plugin-store` v2：数据持久化存储
  - `tauri-plugin-log` v2：开发期日志（已有）

- **插件注册**（`src-tauri/src/lib.rs`）：

  ```rust
  .plugin(tauri_plugin_store::Builder::default().build())
  ```

- **权限配置**（`src-tauri/capabilities/default.json`）：

  ```json
  "permissions": [
    "core:default",
    "shell:allow-open",
    "shell:allow-execute",
    "shell:default",
    "store:allow-load",
    "store:allow-get",
    "store:allow-set",
    "store:allow-delete",
    "store:allow-save",
    "store:default"
  ]
  ```

- **窗口配置**（`src-tauri/tauri.conf.json`）：

  ```json
  "app": {
    "windows": [
      {
        "title": "系统信息查看器",
        "width": 1200,
        "height": 800,
        "resizable": true,
        "fullscreen": false,
        "dragDropEnabled": true
      }
    ]
  }
  ```

- **核心命令：`launch_app`**（`src-tauri/src/lib.rs`）：

  ```rust
  /// 启动本地应用程序（批量打开由前端循环调用该命令实现）
  ///
  /// 为了避免 JS 侧 shell 插件 scope、URL 校验等限制，
  /// 这里直接在 Rust 端使用 `cmd /C start` 启动指定路径的程序。
  #[tauri::command]
  fn launch_app(path: String) -> Result<(), String> {
      #[cfg(target_os = "windows")]
      {
          StdCommand::new("cmd")
              .arg("/C")
              .arg("start")
              .arg("")
              .arg(&path)
              .spawn()
              .map_err(|e| format!("failed to launch app: {}", e))?;
          Ok(())
      }

      #[cfg(not(target_os = "windows"))]
      {
          Err("launch_app is only implemented for Windows".to_string())
      }
  }
  ```

  在 `invoke_handler` 中注册：

  ```rust
  .invoke_handler(tauri::generate_handler![
    get_system_info,
    get_cpu_info,
    get_memory_info,
    get_disk_info,
    fetch_url,
    parse_html_by_selector,
    scrape_page,
    launch_app
  ])
  ```

### 前端（Vue3 + Ant Design Vue）

#### 1. 数据持久化模块（`src/composables/useAppStore.js`）

- 使用 `@tauri-apps/plugin-store` 管理应用列表：

  - `loadApps()`：从 store 读数据
  - `saveApps()`：写入并持久化
  - `addApp(path, name)`：去重 + 规范化路径（统一 `\\`）后追加
  - `removeApp(id)` / `removeApps(ids)`：单删 / 批量删

- store 文件：`app-launcher.json`

#### 2. UI 组件（`src/components/AppLauncher.vue`）

- 顶部 `AppLauncher` 卡片：
  - 场景选择下拉框（当前显示/操作的场景）
  - 批量删除按钮（仅作用于当前场景）
  - 「启动选中」与「本场景全部」两个按钮

- **拖放区域**：
  - 使用 `webviewWindow.onDragDropEvent` 监听 `over/leave/drop`
  - `drop` 时拿到 `event.payload.paths`，交给 `handleFileDrop`

- **批量打开**：


## 使用说明

1. 启动应用：

   ```bash
   npm run tauri:dev
   # 或
   yarn tauri:dev
   ```

2. 在「应用批量启动器」卡片中：
   1. 将程序快捷方式 / 可执行文件拖放到拖放区域
   2. 确认下方列表中已出现应用
   3. 勾选需要删除的应用，点击「批量删除」可移除
   4. 点击「批量打开」按钮，一次性启动全部应用

## 注意事项

- 当前 `launch_app` 仅在 **Windows** 下实现，其他平台会返回错误
- 拖入 `.lnk` 快捷方式时，使用的是快捷方式文件本身，Windows 会自动解析目标
- 批量启动时每个程序间隔 ~300ms，避免瞬时高峰
- 应用列表数据保存在 Tauri Store 中，卸载应用不会自动清理
