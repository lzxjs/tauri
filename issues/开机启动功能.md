# 开机启动功能实现

## 需求
在 `a-layout-header` 添加开机启动功能，点击可以切换该软件开机启动或开机不启动。

## 实施方案
使用 Tauri 官方的 `tauri-plugin-autostart` 插件实现跨平台开机自启动功能。

## 实施步骤

### 1. 添加依赖
- 前端：`npm install @tauri-apps/plugin-autostart`
- 后端：`cargo add tauri-plugin-autostart`

### 2. 配置 Tauri 插件
- 在 `src-tauri/src/lib.rs` 的 `setup` 函数中初始化 autostart 插件
- 使用 `#[cfg(desktop)]` 条件编译确保仅在桌面平台启用

### 3. 配置权限
- 在 `src-tauri/capabilities/default.json` 中添加权限：
  - `autostart:allow-enable`
  - `autostart:allow-disable`
  - `autostart:allow-is-enabled`

### 4. 前端实现
- 导入 `@tauri-apps/plugin-autostart` 的 API：`enable`, `disable`, `isEnabled`
- 添加状态管理：`autostartEnabled`, `autostartLoading`
- 实现切换函数 `toggleAutostart`
- 在组件挂载时检查当前状态
- 在 header 中添加 `a-switch` 组件

### 5. 样式优化
- 添加 `.header-actions` 容器样式
- 添加 `.autostart-label` 标签样式
- 修复 `:deep` 语法警告

## 文件修改清单
- ✅ `package.json` - 添加前端依赖
- ✅ `src-tauri/Cargo.toml` - 添加 Rust 依赖
- ✅ `src-tauri/src/lib.rs` - 初始化插件
- ✅ `src-tauri/capabilities/default.json` - 配置权限
- ✅ `src/App.vue` - 实现 UI 和逻辑

## 功能说明
- Header 右侧显示"开机启动"开关
- 点击开关可切换开机启动状态
- 状态持久化，重启应用后保持
- 操作成功/失败有消息提示
- 支持 Windows/macOS/Linux 跨平台
